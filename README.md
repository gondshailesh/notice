# Notice Board

A simple **Notice Board Web Application** developed using **PHP and Laravel**. This project is created to practice Laravel development and build a practical portfolio project.

## 📌 About the Project

The Notice Board application is designed to provide a centralized platform for creating, managing, and displaying important notices.

The project focuses on learning and implementing Laravel concepts such as **MVC architecture, routing, controllers, Blade templates, database migrations, Eloquent ORM, CRUD operations, and form validation**.

## 🛠️ Technologies Used

* **PHP:** 8.2.12
* **Laravel:** 12.69.3
* **Frontend:** HTML, CSS, JavaScript, Blade
* **Database:** SQLite
* **ORM:** Eloquent
* **Dependency Manager:** Composer
* **Build Tool:** Vite
* **Testing:** Pest & PHPUnit
* **Code Formatting:** Laravel Pint
* **Local Environment:** XAMPP
* **Version Control:** Git & GitHub

## ⚙️ Installation

### 1. Clone the Repository

```bash
git clone <your-github-repository-url>
```

### 2. Open the Project

```bash
cd notice
```

### 3. Install PHP Dependencies

```bash
composer install
```

### 4. Create Environment File

```bash
copy .env.example .env
```

### 5. Generate Application Key

```bash
php artisan key:generate
```

### 6. Run Database Migrations

```bash
php artisan migrate
```

### 7. Start Laravel Development Server

```bash
php artisan serve
```

Open the application in your browser:

```text
http://127.0.0.1:8000
```
